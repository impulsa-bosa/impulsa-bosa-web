# Impulsa Bosa

Sitio web de Impulsa Bosa: marketing digital accesible para pequeños negocios de Bosa y Bogotá.

Sitio estático (HTML, CSS y JS), sin dependencias ni proceso de compilación. Compatible con GitHub Pages.

## Estructura
- `index.html`: contenido y estructura
- `css/styles.css`: estilos
- `js/main.js`: menú móvil, animaciones, formulario y botón de copiar correo
- `assets/favicon.svg`: icono

## Publicar
Sube estos archivos a la raíz del repositorio (rama `main`) y activa GitHub Pages en Settings → Pages.
